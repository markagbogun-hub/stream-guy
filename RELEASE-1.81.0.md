# RadioCastOS 1.81.0 — AI Programme Director

## Delivered
- A new `src/ai_programme_director.py` service to build a timed programme rundown from approved, existing local assets.
- Configurable duration, station-ID cadence, sweeper cadence, commercial cadence, opening news, and closing presenter link.
- JSON rundown persistence, offsets, duration totals, and warnings when available assets cannot fill the target.
- Explicit per-run authorization before queue handoff and duplicate-submission prevention.
- Deterministic playout remains authoritative; this service does not start or stop the player.

## Requirements / boundaries
- Caller must supply actual, approved local audio files with durations. Fresh news must be fetched and validated by the existing news workflow; voice segments must be generated by the configured TTS workflow.
- A queue handoff only submits items to the configured sink; it does not confirm the output device or stream is live.
- This release adds a backend service and regression tests. It is not yet exposed as a new dedicated GUI wizard/button.
