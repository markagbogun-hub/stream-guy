# RadioCastOS 1.77.1 — Premium AI Presenter Command Center

This is a focused UI/productization release on top of 1.77.0.

## Highlights
- Presenter Command Center under AI Studio.
- Broadcast clock with current/next context and remaining time.
- Approved presenter-break script preview.
- One-touch Prepare, Load Ready, Take Presenter On Air and Auto Program actions.
- Clear presenter health/state and broadcast safety messaging.
- Producer role access with Technician visibility preserved.

## Safety
The Command Center is presentation-only. It calls the existing RadioCastOS AI Presenter and player methods and does not create a second playout path. Emergency Stop remains authoritative.
