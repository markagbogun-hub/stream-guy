# RadioCastOS 1.72.0 — Copilot Operator UI

## Summary

1.72.0 adds the operator-facing Live Show Copilot workspace on top of 1.71.0.

## Operator surface

- Current and next item awareness
- Remaining-time countdown
- Presenter cue countdown
- Transition cues
- Individual/bulk acknowledgement
- Talking points
- Breaking/developing-news advisories
- Show context and headline refresh
- Queue revision correlation

## Safety boundary

The UI is presentation/advisory only. It does not mutate the authoritative broadcast queue or replace deterministic playout authority.
