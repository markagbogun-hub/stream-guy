How to install RadioCastOS

Requires Windows 10 or 11 (64-bit). Download RadioCastOS-Setup.exe, then follow these steps.

1. Windows may warn you. This is normal.

RadioCastOS is new software from a small publisher, so Windows SmartScreen shows a warning for any program it has not seen many people install yet. It does not mean the file is infected.

  1. Double-click RadioCastOS-Setup.exe.
  2. When the blue "Windows protected your PC" window appears, click More info.
  3. Click Run anyway.

If your browser blocks the download first: in Edge choose Keep, then Show more, then Keep anyway; in Chrome choose Keep. Only run installers downloaded from this page.

2. Install

Click Yes at the Windows permission prompt (the publisher may show as Unknown), then Next through the wizard and Install.

3. Enter your licence key

RadioCastOS starts in the free Basic package. After you buy, press Enter licence key, paste the key from your email and press Activate.
