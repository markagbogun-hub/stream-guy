# Automation quick start

Three ways in. Pick the one that suits you.

## 1. Try it first (2 minutes)
1. Automation page > **Demo setup…** > Yes. Wait a few seconds while the demo audio is made.
2. Tick **Enable 24/7 AutoDJ**. Songs are about 12 seconds long, so you will hear an ad break within half a minute.
3. Watch **NEXT 10** to see songs, ad breaks, jingles and station IDs lined up.
4. **Replace demo files…** swaps each demo file for one of your own, one at a time, everywhere it is used. Do a few now, the rest tomorrow.
5. When you are happy, press **Keep demo as my setup**. Or **Restore my setup** to go back exactly as it was.

## 2. Build it yourself
1. **Program & content:** select tracks in Library & Playlist, then press **Music** (or Jingle, Station ID, Sweeper, Promo, News). Press **Save Program**.
2. **Clock → Schedule:** tick the days, pick a time block (or type 6am / 18:30), choose the program, press **Add to schedule**. No schedule at all means AutoDJ runs 24/7. If you do add a schedule, any time it does not cover is silent: the week bar shows the gaps.
3. **Quick commercial setup…:** choose the advert audio, name it, pick how long it runs and how often (Light, Normal, Heavy).
4. Tick **Enable 24/7 AutoDJ**.

## 3. Check it
The line of ticks under the switches shows what is missing: music, station IDs and jingles, commercials, schedule coverage, audio files that can no longer be found. The coloured line at the top of the page explains every button press, including why one could not do anything.

## Ad and ID pacing
**Ads every N songs / spots / ID every N songs** (Professional Radio Clock) or the **Light / Normal / Heavy** buttons. Ads also play at the break minutes set in the Broadcast Clock Editor; the two work together.
